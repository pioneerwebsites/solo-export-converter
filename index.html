HOW TO USE

Step-by-step Instructions

  1. Download your website data from Solo, then drop the ZIP file in the box above.
  2. Check the image status for each site. Some images can't currently be downloaded by the tool due to an issue at Solo's end, we're working on it. In the meantime, you should right click on the remote link and Choose "Save Link As..." then upload those images manually.
  3. Download the completed ZIP file for the site.
  4. Go to Cloudflare Drop and drop this new ZIP file on the page.
  5. The site will be uploaded to a temporary domain. Press the "Claim" button and follow the steps to create a Cloudflare account.
  6. After you've made your Cloudflare account, use the "Add a domain" box to connect it to your domain, follow the steps to change your nameservers.
  7. Repeat the process for any additional sites.

Still need help? Ask a chatbot or talk to one of our human experts.

IMPORTANT NOTES

What you need to know

  • Dynamic page elements such as contact forms will no longer work. If this is a feature you need, have a chat with us.
  • When Solo goes offline, so will their editing tools. Unless you are willing to get into the nitty-gritty of HTML and CSS you can't edit your website anymore. If this is a problem, you need a CMS.
  • Image downloads require CORS permission from the source server. Right now Solo is blocking this permission. We've asked them to relax the restriction so users can easily export their images too. This would be a nice gesture of goodwill, and we'll update with their response. In the meantime, if a request is blocked, download the image yourself and use the manual import option.
  • Cloudflare drag-and-drop permits 1,000 files and 25 MiB per file. Scripts, embeds and links to external resources may remain. You should review each site before publishing.
  • Images are saved with filenames corresponding to their page section. This is much better for SEO than the way Solo saved them originally.
  • Never publish contacts.csv. It may contain personal information.
