HOW TO USE

Publish to Cloudflare Pages

  1. Download your website data from Solo, then select the exported ZIP above.
  2. Check image status for each site and download its generated ZIP.
  3. In Cloudflare, open Workers & Pages, create a Pages project, and choose Drag and drop.
  4. Upload the generated ZIP. Repeat for any additional sites and connect your domain if needed.

IMPORTANT NOTES

What to check afterwards

  • Solo contact and newsletter forms will not work without a replacement form service.
  • Image downloads require CORS permission from the source server. If a request is blocked, download the image yourself and use the manual import option.
  • Cloudflare drag-and-drop permits 1,000 files and 25 MiB per file. Scripts, embeds and links to external resources may remain. Review each site before publishing.
  • Never publish contacts.csv. It may contain personal information.
